# Notices

This repository provides unofficial rebuilds of Flameshot for macOS 11+ (arm64).

- Upstream project: https://github.com/flameshot-org/flameshot
- Upstream license: GPL-3.0 (see `LICENSE`)
- Build configuration: Qt 6.7.3, `CMAKE_OSX_ARCHITECTURES=arm64`, `CMAKE_OSX_DEPLOYMENT_TARGET=11.0`
- Corresponding source for each binary: the upstream release tag listed in that release, plus any patches in `patches/`

These builds are not affiliated with or endorsed by the Flameshot project.
